# Untrodden

> 눈 덮인 산을 스키로 내려가며 깃발 관문을 통과하고, 눈보라를 뚫고 바닷가 마을까지 가장 빠르게 도착하는 VR 스키 타임어택 게임

| 항목 | 내용 |
|---|---|
| 과제 주제 | 주제 B. XR Interaction Toolkit을 활용한 VR 게임 |
| 플랫폼 | Meta Quest (Android APK) |
| 개발 환경 | Unity 6000.3, URP, OpenXR + Unity OpenXR: Meta, XR Interaction Toolkit 3.5.1 |
| 사용 XR 기능 | 스키 이동(XRI `LocomotionProvider` 확장, 폴 동작 인식), 연속 이동·부드러운 회전, 터널링 비네팅, 레이 UI(시작·결과 화면), 컨트롤러 햅틱 |
| 마감 | 11/16 컨셉 기획서 제출 · 11/23 1차 빌드 및 시연 영상 제출 |

> 설계 결정과 그 이유: [docs/design-decisions.md](docs/design-decisions.md)

## 1. 작업지시서 대조

| 지시서 요구사항 | 대응 | 판정 |
|---|---|---|
| XRI 상호작용 2종류 이상 | 레이 UI(시작·결과 버튼), XRI 로코모션(스키·걷기·부드러운 회전), 컨트롤러 햅틱 | ⚠️ 폴을 처음부터 들고 시작하도록 바꾸면서 잡기가 빠짐. 잡기 요소 추가 검토 |
| 시작 → 플레이 → 끝 흐름 | 시작 화면 → 활강 → 결승선 통과 → 결과 화면 | ✅ |
| 점수·시간·승패 중 1개 이상 표시 | 최종 기록(주행 + 벌점), 통과 관문 수, 충돌·재출발 횟수 | ✅ |
| Quest에 APK로 설치해 실행 | Android APK, Quest 3S에서 실행 확인 | ✅ |
| 튕김·멈춤 없음, 끊김 없는 성능 | 안개 42m + 카메라 렌더 거리 46m, 72fps 유지 확인(시작 지점 기준) | ⚠️ 활강·눈보라 중 측정 필요 |
| 멀미 고려 (스냅 회전, 강제 카메라 이동 금지) | 멈췄을 때 회전은 초당 50° 부드러운 회전 + 비네팅, 이동은 플레이어가 폴로 직접 일으킴(밀어야 출발), 비탈 최고 시속 45km(폴로 계속 밀 때만 잠깐 그 이상), 이동 중 비네팅, 흔들림 없는 피격 연출 | ⚠️ 스냅 대신 부드러운 회전을 택한 이유(회전 중 비네팅, 천천히 돌아 방향 감각 유지)와 경사 가속을 발표 때 설명 |
| 시연 영상 시작 화면에 앱 이름과 본인 이름 | 시작 화면에 "Untrodden", "제작 채경희" | ✅ |

**핵심 경험:** 양손으로 폴을 밀고 끌며 나무 사이 슬로프를 내려간다. 관문을 놓치지 않으면서 눈보라가 체력을 깎기 전에 모닥불과 결승선에 닿아야 한다.

## 3. 기능별 구현 방법

| 기능 | 구현 |
|---|---|
| 스키 이동 | `SkiController`가 XRI `LocomotionProvider`를 상속. 지형 법선으로 경사 방향 가속을 계산하고 마찰·공기저항을 뺀다. 비탈 중력으로는 시속 45km까지, 폴로 계속 밀면 시속 65km까지 넘어가고 넘은 속도는 초당 35%씩 상한 쪽으로 줄어듦. 속도감: 이동 거리에 비례해 시야 앞에 뿌리는 눈가루, 속도에 따라 커지고 높아지는 바람 소리, 빠를 때 약한 진동. `CharacterController.Move`로 지면을 따라 이동 |
| 폴 동작 | 양손 컨트롤러에 처음부터 폴이 붙어 있고(주먹 아래로 뻗음), `SkiPole`이 폴 **각도**로 눈을 짚었는지 판정(바로 아래에서 40° 이내면 짚음, 손목을 젖혀 끝을 뒤로 들면 뗌). 손 높이를 쓰지 않아 앉아서도 손을 늘어뜨릴 필요 없음. 닿는 순간 짧은 햅틱, 미는 동안 약한 햅틱. 몸 기준 손 속도가 스키 방향 뒤쪽으로 빠르면 **추진**. 폴이 닿아만 있는 건 감속하지 않음(한 번 밀면 계속 미끄러짐) |
| 한 손 밀기 | 한쪽 폴로만 밀면 반대쪽으로 돈다(오른쪽을 밀면 왼쪽으로). 양손 미는 세기 차이에 비례, 최대 초당 45°. 감속 없이 조금 가속하며 돌고, 화면도 함께 돌려 손 방향 조향과 겹치지 않음 |
| 눈높이 | 트래킹 기준점과 서기·앉기에 상관없이 지면에서 눈까지 1.6m로 고정(시작·재조정 때 카메라 오프셋 보정). 알림은 시야 중심 약 5° 아래·1.6m 거리에 띄워 렌즈 가장자리 흐림을 피함 |
| 조향·감속 | 양손 컨트롤러가 가리키는 수평 방향의 평균을 스키 방향과 비교해, 8° 넘게 벌어지면 그쪽으로 최대 초당 70°까지 천천히 돈다. 고개 방향은 쓰지 않아 둘러봐도 방향이 안 바뀜. 화면을 강제로 돌리지 않고 몸으로 돈다. 크게 꺾을수록 눈을 긁으며 감속하고, 슬로프를 가로지르면 중력 가속도 줄어듦 |
| 시작 방향 | **시작 버튼을 누르는 순간** 출발 지점에서 슬로프 아래를 보도록 리그를 돌림(이때는 확실히 헤드셋을 쓰고 있음). 시작 화면은 고개를 30° 넘게 돌리면 정면으로 따라와서 어떤 방향으로 켜져도 보임. 보조로 시작 화면에 있는 동안 트래킹이 잡힐 때·포커스 복귀(헤드셋 착용, 시스템 팝업 닫힘)·화면 재조정 때마다 출발 지점에서 슬로프 아래를 보도록 리그를 돌림. 시작 화면을 1.5초 넘게 등지고 있어도 다시 맞춤. 공간 데이터 권한 팝업이 뜨지 않도록 쓰지 않는 MR 기능(평면·메시·바운딩 박스·가림)은 끔. 멈춰 있을 때는 스키가 시선 방향을 따라가서 바라보는 쪽으로 출발 |
| 저속 이동 | 거의 멈췄을 때만 XRI 연속 이동(왼쪽 스틱)·부드러운 회전(오른쪽 스틱, 초당 50°)을 켬. 순간이동은 쓰지 않음 |
| 멀미 방지 | 스키 비네팅은 속도에 비례(시속 7km 이하 없음 → 최고 속도에서 시야 55%), 걷기·회전 중 비네팅, 정지 시 천천히 도는 회전, 정지 마찰(폴로 밀어야 출발), 피격 시 화면 흔들림 없이 붉은 테두리 |
| 충돌 | 옆면 충돌로 의도한 이동의 절반도 못 가면 충돌로 판정 → 정지, 속도 비례 체력 감소, 양손 햅틱, 충돌음 |
| 관문 | 관문 평면을 넘는 순간 좌우 거리로 통과·누락 판정. 뒤 관문을 먼저 넘으면 앞 관문은 누락. 누락 1개당 +5초 |
| 모닥불 | 가까이 지나가면 점화 + 체크포인트 저장 + 체력 완충. 체력 0이면 마지막 모닥불에서 재출발 |
| 눈 셰이더 | 직접 만든 셰이더 과제(3rd-study-shader)의 `Blizzard` 셰이더를 가져와 Quest 양쪽 눈에 그려지도록 스테레오 매크로를 추가. 텍스처 없이 눈송이 모양·모션 블러·거리 흐림을 계산. 주된 눈·얼굴 앞 큰 눈·눈보라 때 눈가루 덩어리 3겹, 평소 ↔ 눈보라에 따라 양과 바람을 보간 |
| 눈보라 | 무작위 타이머 → 20초 예고(바람·손목 알림) → 30초간 체력 감소, 안개가 16m까지 짙어지고 렌더 거리도 함께 축소, 눈이 바람에 옆으로 날림 |
| 손목 HUD | 기록(벌점 표시), 속도, 체력, 관문 수, 눈보라 예고, 나침반(바라보는 방향 기준 N과 다음 관문 화살표) |
| 길 잃음 대비 | 플레이 영역 둘레 보이지 않는 벽, 영역 밖·지형 아래로 떨어지면 자동 복귀, 왼쪽 메뉴 버튼 길게 = 모닥불로 복귀 |
| UI | World Space Canvas + Tracked Device Graphic Raycaster |
| 맵 생성 | 에디터 스크립트(`Untrodden > Build Scene`)가 지형·코스·숲·관문·UI를 코드로 생성. 경사 프로파일을 적분해 평균 17° 산비탈을 만들고, 굽이진 슬로프 바깥에만 나무를 3.8m 간격으로 배치 |
| 최적화 | 안개 끝 거리 ≈ 카메라 Far Clip, 눈 덮인 Synty 재질 공유 + SRP Batcher, 그림자 끔 |

## 5. 개발 환경 준비 (다른 PC에서 열 때)

1. Unity 6000.3.15f1로 프로젝트를 연다.
2. Synty 애셋 2개를 임포트한다(유료 라이선스·용량 문제로 git에 포함하지 않음).
   - `POLYGON_Nature_Unity_2022_3_v1_2_1.unitypackage`
   - `POLYGON_NatureBiomes_EnchantedForest_Unity_2022_3_v1_6_4.unitypackage`
3. `Assets/Untrodden/Scenes/Untrodden.unity`를 연다. 씬을 다시 만들려면 메뉴 `Untrodden > Build Scene` (에디터에서 손으로 바꾼 내용은 덮어써짐).
4. APK 빌드: 메뉴 `Build > Quest APK` → `Builds/Android/Untrodden.apk`

## 6. 발표 자료

- **앱 이름:** Untrodden
- **한 줄 소개:** 눈 덮인 산을 스키로 내려가며 깃발 관문을 통과하고 바닷가 마을까지 가장 빠르게 도착하는 VR 스키 타임어택
- **사용한 XR 기능:** XRI 로코모션 확장(폴 동작으로 움직이는 스키 Provider), 연속 이동·부드러운 회전, 터널링 비네팅, 레이 UI, 햅틱
- **주요 기능:** 폴 추진·양손 방향 조향, 깃발 관문 타임어택, 충돌 체력, 눈보라, 모닥불 체크포인트, 손목 HUD 나침반
- **느낀점:** (개발 후 작성)
