# Untrodden

> 눈보라와 곰을 피해 얼어붙은 숲을 가로지르고, 강을 따라 바닷가 마을까지 살아서 도착하는 VR 생존 탐험 게임

| 항목 | 내용 |
|---|---|
| 과제 주제 | 주제 B. XR Interaction Toolkit을 활용한 VR 게임 |
| 플랫폼 | Meta Quest (Android APK) |
| 개발 환경 | Unity 6000.3, URP, OpenXR + Unity OpenXR: Meta, XR Interaction Toolkit 3.5.1 |
| 사용 XR 기능 | 걷기·순간이동(스냅 회전, 비네팅), 잡기(나침반·장작·소총·음식), 소켓 끼우기(모닥불에 장작, 총알 장전), 레이 UI(시작·결과 화면) |
| 마감 | 11/16 컨셉 기획서 제출 · 11/23 1차 빌드 및 시연 영상 제출 |

## 1. 작업지시서 대조

| 지시서 요구사항 | 기획서 대응 | 판정 |
|---|---|---|
| XRI 상호작용 2종류 이상 | 잡기, 소켓, 순간이동, 레이 UI | ✅ |
| 시작 → 플레이 → 끝 흐름 | 시작 화면 → 탐험 → 마을 도착 | ✅ |
| 점수·시간·승패 중 1개 이상 표시 | 걸린 시간, 다시 시작한 횟수, 걸은 거리 | ✅ |
| Quest에 APK로 설치해 실행 | Android APK | ✅ 첫날 빌드 확인 |
| 튕김·멈춤 없음, 끊김 없는 성능 | 안개와 풀링으로 최적화 | ⚠️ 중점 관리 |
| 멀미 고려 (스냅 회전, 강제 카메라 이동 금지) | 스냅 회전, 비네팅, 화면 흔들림 없는 피격 연출 | ✅ |
| 시연 영상 시작 화면에 앱 이름과 본인 이름 | — | ➕ 시작 화면에 추가 |

**핵심 경험:** 눈보라가 오기 전에 장작을 끼우고 불을 붙여 살아남으며, 지형을 보고 마을까지 길을 찾는다.

## 3. 기능별 구현 방법

| 기능 | 구현 |
|---|---|
| 이동·회전·멀미 방지 | Starter Assets XR Origin, Snap Turn, Tunneling Vignette(연속 이동 중에만). 부족하면 순간이동을 기본으로 전환 |
| 나침반 | `XRGrabInteractable`, 바늘이 매 프레임 월드 북쪽을 가리킴 |
| 장작 끼우기 | 모닥불 자리의 `XRSocketInteractor` 2~3개, 장작 태그만 허용 |
| 파이어스틱 점화 | 양손에 든 두 물체의 충돌 시 상대 속도 측정 → 일정 속도 이상 N회면 불꽃 파티클 후 점화 |
| 모닥불 | 점화 시 체크포인트 저장, 주변 영역에서 추위 회복 |
| 체력 | 내부 수치(추위·배고픔·갈증)의 감소량을 하나의 체력으로 합산, 손목 UI에 부족한 원인 아이콘 표시 |
| 눈보라 | 랜덤 타이머 → 30초 예고(소리·하늘·손목 알림) → 추위 감소 배율 증가, 모닥불·바위 그늘 영역은 완화 |
| 곰 | 상태머신(배회 → 경계·으르렁 → 추적 → 공격), 지형 높이 보정 직선 추적. 으르렁 소리는 안개 거리보다 멀리 들림 |
| 소총 | 총알 소켓 장전, Activate로 레이캐스트 발사 + 햅틱 |
| 먹기 | 머리 트리거 콜라이더에 음식을 가져가면 섭취 |
| 피격 연출 | 화면 흔들림 없이 붉은 테두리 비네트 + 사운드 |
| UI | World Space Canvas + Tracked Device Graphic Raycaster |
| 결과 집계 | 걸린 시간, 리스폰 횟수, 이동 거리(순간이동 포함) |
| 안개·최적화 | URP 안개 끝 거리 = 카메라 Far Clip, 나무 GPU 인스턴싱 + 풀링, 72fps 목표 |

### 무작위 맵 생성 (추가 기간)
- 남쪽이 높고 북쪽이 바다가 되도록 기울기를 깔고 Perlin 노이즈를 더한 높이맵, 시드로 판마다 변경
- 남쪽 수원에서 가장 낮은 이웃 칸으로 내려가며 바다까지 강 경로를 만들고 지형을 깎음 → "물은 아래로, 강은 바다로" 보장
- 강과의 거리에 따라 곰·음식 밀도를 조절해 "편한 길에 리스크" 표현
- 지형은 시작 시 한 번 생성하고 나무·소품만 플레이어 주변에서 풀링 (안개가 경계를 가림)
